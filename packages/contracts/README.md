# Contracts Package

**Status:** G09 V1 site integration contract implemented.

Exports runtime validation, TypeScript types, JSON Schema, deterministic hashes, and compatibility checks for routes, components, fields, protected fact references, previews, builds, and bounded contact forms. Additive changes are accepted; breaking stable-ID, route, type, or protection changes require an explicit migration.

Validate with `npm run verify:goal -- G09`. A custom visual design is allowed only after its manifest passes this contract and the site build checks.
