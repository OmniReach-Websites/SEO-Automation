# Starter Site

**Status:** G10 fictional Astro reference site implemented; G13 reusable contact surface is inert by default.

Copper Spoon is a conspicuously fictional, static-first restaurant fixture demonstrating the integration manifest, structured editable fields, protected hours, contact declaration, responsive accessible pages, metadata, JSON-LD, sitemap, and robots output.

Run `npm run build --workspace @omnireach/site-starter` and `npm run check:site-builds`. No content, domain, recipient, consent wording, or legal text in this fixture is real or approved for production use. The form remains disabled unless its same-host public configuration endpoint reports an enabled and verified configuration.
