# Restaurant Example

**Status:** G10 custom-design contract fixture implemented.

Night Market is a fictional restaurant design intentionally distinct from the starter while using the same OmniReach integration contract. It proves custom frontend freedom does not bypass stable fields, protected facts, build output, metadata, or validation requirements.

Run `npm run build --workspace @omnireach/site-restaurant-example` and `npm run check:site-builds`. The fixture contains no real customer data or production integrations.
