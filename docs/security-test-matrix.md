# Security and Race Test Matrix

| Boundary              | Required invariant                                                                                             | Automated evidence                                                                                          | Remaining production evidence           |
| --------------------- | -------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| Host/session          | A session is valid only on its recorded verified host and site                                                 | auth integration, application-boundary and tenant-context suites                                            | post-deploy exact-host smoke            |
| Customer roles        | Owner/editor/viewer permissions are server-side and protected fields remain owner/manual only                  | customer route and content-field-role suites                                                                | customer acceptance exercise            |
| Cross tenant/site     | Reads, writes, jobs, domains, drafts, forms, assets, publications, integrations and reports cannot cross scope | disposable PostgreSQL RLS tests; tampered job tests; ORAP analytics direct-object and platform-policy tests | staging migration run                   |
| Pool reuse            | `SET LOCAL` context disappears after transaction/rollback                                                      | PostgreSQL context and local-stack checks                                                                   | runtime pool telemetry review           |
| Concurrent auth       | identity lock plus complete transaction retries prevent stale recovery/session commits                         | auth race and recovery tests                                                                                | production-equivalent contention drill  |
| Revoked/stale session | revocation/auth-state changes invalidate challenge completion and subsequent access                            | authentication service/schema tests                                                                         | post-deploy logout/session-revoke smoke |
| TOTP                  | secret encrypted by versioned key; counter replay rejected; enrollment/disable revoke sessions                 | auth service, MFA rotation and schema tests                                                                 | voluntary owner enrollment exercise     |
| WebAuthn              | exact origin/RP/site, one-use ceremony, credential/sign counter and session issuance are atomic                | WebAuthn unit/security/schema tests                                                                         | two-device browser exercise             |
| Factor loss           | revoke requires current password/recent session and cannot remove the last usable customer recovery path       | WebAuthn repository/service tests and runbook                                                               | owner-approved lost-factor exercise     |
| Host spoofing/CSRF    | server resolves verified host; state changes require exact same origin                                         | route, client-network and application-boundary suites                                                       | reverse-proxy header smoke              |
| OAuth                 | state/nonce/PKCE/replay, exact redirect/property and encrypted tokens                                          | Google unit/route/schema tests                                                                              | real project/property consent test      |
| AI                    | disabled gate precedes spend/provider; protected facts and ceilings fail closed                                | AI provider/policy/evaluation/budget suites                                                                 | paid provider remains disabled          |
| Backup/restore        | authenticated ciphertext, checksums, safe path, isolated target and production guard                           | backup and off-site harnesses                                                                               | timed R2 restore drill                  |

Any failed cross-tenant, authentication, protected-fact, secret-leak or restore-integrity check is a release blocker. Tests never authorize relaxing RLS, setting a production bypass role, logging credentials, or substituting mock provider results for production evidence.
